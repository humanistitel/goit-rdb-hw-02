## Схема

Кожна підписка належить одному клієнту й одному тарифу; клієнт і тариф можуть мати багато підписок. SQL створює таблиці, додає тестові записи й виконує AS-OF JOIN.

Дані синтетичні: 12 історичних версій ознак і 6 подій навчання. Інтервали `[valid_from, valid_to)` визначають, яка версія чинна на дату події. Перевірка перекриття виявляє кілька версій для однієї події. У цьому прикладі час набуття чинності збігається з часом доступності даних; для запізнілих подій потрібен окремий час надходження.

Notebook містить DDL, INSERT, нормалізацію, AS-OF запити й Reflection. `er_diagram.mmd` — окремий редагований файл діаграми.
